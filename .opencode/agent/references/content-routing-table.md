# 内容组装路由表

组装 = 从参考材料中取出内容，写入目标 .docx。
**无论哪条路径，写入的内容必须使用目标文档的样式。**

## 路由规则（按源文件格式选择路径）

| 源文件格式 | 路径 | 操作 |
|-----------|------|------|
| .docx | A: 格式保真复制 | 加载 `docx` skill → XML 层面复制章节 → 对齐样式 → tracked changes |
| .pdf / .xlsx / .pptx | B: 提取+写入 | 加载对应格式 skill 提取内容 → 加载 `docx` skill 写入目标 |
| .doc (旧版) | C: 转换后走 A | `pandoc` / LibreOffice 转 .docx → 走路径 A |
| 图片 | D: 按意图决定 | 作为图片插入 或 提取信息后按路径 B 写入（不要假设，问用户） |

## 内容来源优先级

1. 格式保真复制（路径 A）→ 保真度最高
2. 提取+写入（路径 B/D）→ 需对齐样式
3. 从零生成 → 最后手段，仅当无源材料且用户确认时使用

（详细规则见 bid-drafting skill）

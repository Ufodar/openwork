# 模板探测流程（Template Probing）

当优先级 1（用户已上传模板）不满足时，对用户提供的源文件包执行以下探测。

**如果 `.worktree/index.json` 中已经存在 `template_findings` 或明确的 `target_doc`，优先使用现有结果，避免重复扫描。**

**如果已经存在经过分类的文件清单**，优先只在模板、附件或格式参考类条目中搜索候选模板，缩小扫描范围。

**探测位置（按优先级）：**

1. **同目录下独立文件** — 检查源文件所在目录是否有名称含 "格式"/"模板"/"空白"/"示例" 的 `.docx` / `.doc` 文件
2. **压缩包** — 如果目录下有 zip/rar 包，解压后搜索模板文件
3. **文档内嵌章节** — 对源文件做结构扫描，查找以下章节标题（不要求精确匹配措辞）：
   - "文档格式" / "响应文件格式" / "模板"
   - "格式及组成" / "文档组成及格式"
   - 位于文档末尾附件/附录中的格式模板

**探测结果处理：**

- **找到独立模板文件** → 创建工作副本（保护原件），将副本路径记录到 `.worktree/index.json` 的 `target_doc`
- **找到内嵌格式章节** → 提取该章节确定的目录结构和格式要求，以此为骨架创建目标文档（保留章节编号、表格框架）
- **均未找到** → 明确记录“暂无模板”，继续走无模板起草路线
- **发现多个候选** → 向用户展示候选列表，请用户选择

**探测必须在分析或撰写开始之前完成。**

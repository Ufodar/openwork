# 商务标常见章节结构

以下为中国政府采购投标文件商务部分的典型章节结构，实际以招标文件要求为准。

## 一、投标函及附件

1. 投标函
2. 法定代表人授权委托书
3. 投标保证金缴纳证明

## 二、资格证明文件

1. 营业执照副本
2. 税务登记证 / 三证合一
3. 财务审计报告（近三年）
4. 社会保险缴纳证明
5. 纳税证明
6. 信用记录查询结果（信用中国 / 中国政府采购网）

## 三、商务资质与业绩

1. 类似项目业绩证明（合同 + 验收报告）
2. 厂商授权书
3. 产品代理资格证明
4. 相关行业资质证书（如系统集成资质、ISO 认证等）

## 四、商务条款响应

1. 交货期 / 工期承诺
2. 保修期承诺
3. 付款条件确认
4. 售后服务承诺（响应时间、服务范围）
5. 质保期承诺

## 五、报价部分

1. 开标分项一览表（总价）
2. 设备清单及单价明细
3. 软件清单及报价
4. 服务费用明细（安装、调试、培训等）
5. 报价说明（含税、运费、安装等）

## 六、商务点对点应答表

逐条应答招标文件商务要求，标注偏离情况。

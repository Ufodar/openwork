# 投标文件提交前检查清单

提交前逐项确认，任何 Blocker 级别问题必须修复后才能提交。每项标注验证方式：

- **[确定性脚本]** = check_deterministic.py 完整覆盖，pass 可信赖
- **[确定性脚本初筛 + LLM判断]** = 脚本做粗筛（scope 范围内），LLM 必须补充 uncovered 部分
- **[视觉子agent]** = 视觉子 agent 从图片中提取并校验
- **[视觉子agent + LLM判断]** = 视觉子 agent 提取信息后，LLM 做语义判断
- **[LLM判断]** = 语义分析层检查
- **[人工确认]** = 需用户手动确认

## 废标风险项（Blocker）

- [ ] 星标（★）要求全部满足，无负偏离 **[确定性脚本初筛 + LLM判断]**（脚本只查 CSV 元数据，不验证 docx 实质内容）
- [ ] 投标截止时间确认，所有文件在截止前准备完毕 **[确定性脚本 + 人工确认]**
- [ ] 投标保证金已缴纳且金额正确 **[人工确认]**
- [ ] 投标函已签章 **[人工确认]**
- [ ] 法定代表人授权委托书已签章（如非法人签署） **[人工确认]**
- [ ] 报价未超预算（超预算通常直接废标） **[确定性脚本]**（仅当脚本匹配到报价表时有效，否则为 not_applicable）
- [ ] 投标文件份数满足要求（正本 + 副本） **[人工确认]**
- [ ] 电子版已刻盘 / U 盘准备 **[人工确认]**
- [ ] 所有招标要求的资质证书均已附图且在有效期内 **[视觉子agent + LLM判断]**

## 高风险项（High）

- [ ] 公司名称全文一致，无其他公司名残留 **[确定性脚本初筛 + LLM判断]**（脚本只查存在性+黑名单，不查全称/简称混用）
- [ ] 资质证书有效期覆盖投标截止日 **[视觉子agent + LLM判断]**
- [ ] 资质证书上的公司名与投标公司名完全一致 **[视觉子agent]**
- [ ] 审计报告年份满足要求 **[视觉子agent + LLM判断]**
- [ ] 业绩证明满足招标门槛 **[视觉子agent + LLM判断]**
- [ ] 厂商授权书的产品型号与投标配置一致 **[视觉子agent]**
- [ ] 法人/授权人姓名链一致（执照→委托书→签字人） **[视觉子agent]**
- [ ] 点对点应答表无空行、无笼统"符合" **[确定性脚本初筛 + LLM判断]**
- [ ] 技术参数与厂商资料一致 **[LLM判断]**
- [ ] 报价明细加总 = 总价 **[确定性脚本]**（仅当脚本匹配到报价表时有效，否则为 not_applicable）

## 中风险项（Medium）

- [ ] 页眉页脚正确（公司名、项目名） **[确定性脚本]**
- [ ] 目录页码与实际页码一致 **[人工确认]**
- [ ] 图片清晰可辨认 **[视觉子agent]**
- [ ] 图片与所在章节内容相关（无张冠李戴） **[视觉子agent + LLM判断]**
- [ ] 售后服务承诺与商务条款响应一致 **[LLM判断]**
- [ ] 交货期/工期承诺与多处出现的日期一致 **[确定性脚本初筛 + LLM判断]**（脚本只查 facts.json 日期存在性，不做交叉比对）

## 低风险项（Low）

- [ ] 排版美观、段落间距一致 **[人工确认]**
- [ ] 表格对齐、无断页问题 **[人工确认]**
- [ ] 封面信息完整 **[LLM判断]**
- [ ] 字体字号统一 **[人工确认]**
- [ ] 无 `<<TBD>>` 占位符残留 **[确定性脚本]**

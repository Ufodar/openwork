# 投标文件提交前检查清单

提交前逐项确认，任何 Blocker 级别问题必须修复后才能提交。每项标注验证方式：**[确定性脚本]** = check_deterministic.py 自动检查，**[LLM判断]** = 语义分析层检查，**[人工确认]** = 需用户手动确认。

## 废标风险项（Blocker）

- [ ] 星标（★）要求全部满足，无负偏离 **[确定性脚本]**
- [ ] 投标截止时间确认，所有文件在截止前准备完毕 **[确定性脚本 + 人工确认]**
- [ ] 投标保证金已缴纳且金额正确 **[人工确认]**
- [ ] 投标函已签章 **[人工确认]**
- [ ] 法定代表人授权委托书已签章（如非法人签署） **[人工确认]**
- [ ] 报价未超预算（超预算通常直接废标） **[确定性脚本]**
- [ ] 投标文件份数满足要求（正本 + 副本） **[人工确认]**
- [ ] 电子版已刻盘 / U 盘准备 **[人工确认]**

## 高风险项（High）

- [ ] 公司名称全文一致，无其他公司名残留 **[确定性脚本]**
- [ ] 资质证书有效期覆盖投标截止日 **[LLM判断]**
- [ ] 审计报告年份满足要求 **[LLM判断]**
- [ ] 业绩证明满足招标门槛 **[LLM判断]**
- [ ] 点对点应答表无空行、无笼统"符合" **[确定性脚本初筛 + LLM判断]**
- [ ] 技术参数与厂商资料一致 **[LLM判断]**
- [ ] 报价明细加总 = 总价 **[确定性脚本]**

## 中风险项（Medium）

- [ ] 页眉页脚正确（公司名、项目名） **[确定性脚本]**
- [ ] 目录页码与实际页码一致 **[人工确认]**
- [ ] 图片清晰可辨认 **[人工确认]**
- [ ] 图片与所在章节内容相关（无张冠李戴） **[LLM判断]**
- [ ] 售后服务承诺与商务条款响应一致 **[LLM判断]**
- [ ] 交货期/工期承诺与多处出现的日期一致 **[确定性脚本]**

## 低风险项（Low）

- [ ] 排版美观、段落间距一致 **[人工确认]**
- [ ] 表格对齐、无断页问题 **[人工确认]**
- [ ] 封面信息完整 **[LLM判断]**
- [ ] 字体字号统一 **[人工确认]**
- [ ] 无 `<<TBD>>` 占位符残留 **[确定性脚本]**
